# ravenix - A Nix focused tool for antivirus control and system auditing.

Ravenix will have the following features:

- audit: runs verification in the nix store, looks for unknown setuids and checks against known vulnerabilities.
- defend: checks for sketchy processes running.
- clean: collects nixos garbage and cleans simple caches and temporary files.

Order of priority:
1. Audit
2. Clean
3. Defend
4. Dashboard
